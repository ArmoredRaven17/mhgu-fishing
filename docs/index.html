                Other MHGU Apps

                Companion fan tools by the same author. Each opens in a new tab.

                • Quest Randomizer Rolls random quests when you can't decide what to hunt.
                • Collection Tracker Tracks which weapons, armor and Palico gear you own, and what it costs to finish them.
                • Equipment Box Mirrors the in-game box — 2000 hunter slots and 1000 Palico — so you can plan where things sit.
                • Bingo Builds a bingo card of hunting goals, with a shareable seed so a group can race the same board.
                • Hunting Log Keeps a running record of your hunts — what you were after, what you wore, who came along.
                • Zenny Gauntlet A scored challenge run — fail a hunt or get carted and you lose that weapon/style combo for the rest of the run.
                • Set Builder Assemble a full set by hand and see exactly which skills it activates.
                • Weapon Trees Browse every weapon upgrade tree, with full stats on any node you click.
                • Challenge Run A permadeath challenge run — start from a root weapon, lose it on any quest failure, clear every Key Quest.
                • Charm Farm A Clicker/Idle game about beating up various Brachydios until you finally get the desired God Charms you always wanted.
                • Talisman Bingo A bingo card of talisman conditions — keep drawing charms until one finally fills the line you needed.
                • Fishing you are here A fishing sim on the game's own tables — prepare at camp, travel to a locale, come home with the catch.
